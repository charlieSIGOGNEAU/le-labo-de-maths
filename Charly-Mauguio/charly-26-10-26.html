Fiche 1 · Les ensembles

Dans quelle famille vit ce nombre ?

Les ensembles sont des familles emboîtées. Plus on avance vers la droite, plus il y a de nombres.

ℕ⊂ℤ⊂𝔻⊂ℚ⊂ℝ

ℕ naturels (0, 1, 2…) · ℤ entiers relatifs (… −2, −1, 0, 1…) · 𝔻 décimaux (écriture décimale finie) · ℚ rationnels (fractions) · ℝ réels (tous les nombres de la droite).

−3 ∈ ℤ, mais −3 ∉ ℕ

Et 0,25 ∈ 𝔻 ; √2 ∈ ℝ mais √2 ∉ ℚ.

Mini-test

Le plus petit ensemble de cette liste qui contient −7 ?

Fiche 2 · Image et antécédent

La fonction, c'est une machine

Tu entres un nombre x, la machine calcule f(x), et tu obtiens son image.

Entrée x→× 2 + 1→Sortie f(x)
Entrée
2
→
Image
5

Ici, f(x) = 2x + 1. L'image de 2 est 5.

Trouver une image : on remplace x par le nombre donné.

Trouver un antécédent : on cherche x à partir du résultat. Il peut y en avoir zéro, un ou plusieurs.

f(x) = 2x + 1

Image de 3 : f(3) = 2 × 3 + 1 = 7.

Antécédent de 7 : 2x + 1 = 7, donc x = 3.

À toi

Avec f(x) = 2x + 1, quelle est l'image de 4 ?

Fiche 3 · Ensemble de définition

Quelles entrées sont autorisées ?

L'ensemble de définition, noté Df, contient les valeurs de x pour lesquelles le calcul est possible.

1. Pas de piège : f(x) = 3x − 4

Df = ℝ

2. Racine carrée : g(x) = √(x − 2)

On doit avoir x − 2 ≥ 0, donc x ≥ 2.

Dg = [2 ; +∞[

3. Fraction : h(x) = 1/(x + 3)

Le dénominateur ne doit pas être nul : x + 3 ≠ 0.

Dh = ℝ \ {−3}
Règle express

Pour une racine carrée : ce qui est sous la racine doit être ≥ 0. Pour une fraction : le dénominateur doit être ≠ 0.

Parce que x + 4 ≥ 0, donc x ≥ −4. Son domaine est [−4 ; +∞[.
Fiche 4 · Intervalles

La droite des nombres

Un intervalle décrit une portion de la droite réelle.

[2 ; 5]

2 et 5 sont inclus.

● 2 ━━━━━ 5 ●
]2 ; 5[

2 et 5 sont exclus.

○ 2 ━━━━━ 5 ○

Crochet fermé [ ] : borne incluse. Crochet ouvert ] [ : borne exclue. Avec +∞ ou −∞, la borne est toujours ouverte.

2,5
−5−2147

2,5 appartient à ]2 ; 5[.

Bonus · Intersection de deux droites

Le point où elles se croisent

Pour trouver l'intersection de deux fonctions affines, on cherche quand leurs images sont égales.

f(x) = 2x + 1 et g(x) = −x + 7

1. On résout : 2x + 1 = −x + 7

2. 3x = 6, donc x = 2.

3. On calcule y : f(2) = 5.

Intersection : (2 ; 5)

À retenir : égaliser les deux expressions pour trouver x, puis remplacer x pour trouver y.

02 — À toi de jouer

10–15 min

Fais les exercices sur papier avant d'afficher les corrections. Essaie sans calculatrice si possible.

1
Classer les nombres

Le plus petit intervalle possible

Pour chaque nombre, donne le plus petit ensemble parmi ℕ, ℤ, 𝔻, ℚ, ℝ auquel il appartient.

  1. 12
  2. −4
  3. 2,75
  4. ⅓
  5. √2
  6. 5 − 8
1. ℕ · 2. ℤ · 3. 𝔻 · 4. ℚ · 5. ℝ · 6. ℤ (car 5 − 8 = −3).
On choisit toujours le plus petit ensemble de la chaîne.
2
Ensembles de définition

Autorisé ou interdit ?

Donne l'ensemble de définition de chaque fonction.

  1. f(x) = 4x − 1
  2. g(x) = √(2x + 6)
  3. h(x) = 5/(x − 4)
1. Df = ℝ.
2. 2x + 6 ≥ 0, donc x ≥ −3 : Dg = [−3 ; +∞[.
3. x − 4 ≠ 0, donc x ≠ 4 : Dh = ℝ \ {4}.
3
Intersection

Le point de rencontre

Détermine les coordonnées du point d'intersection des droites représentatives de :

f(x) = 3x − 2
g(x) = x + 4

Écris l'équation à résoudre, puis calcule x et y.

3x − 2 = x + 4, donc 2x = 6 et x = 3. Puis y = 3 × 3 − 2 = 7. Intersection : (3 ; 7).
4
Image ou antécédent ?

Dernier check

Soit f(x) = 5 − 2x.

  1. Calcule l'image de 3.
  2. Trouve l'antécédent de 1.
1. f(3) = 5 − 6 = −1.
2. 5 − 2x = 1, donc −2x = −4 et x = 2.
